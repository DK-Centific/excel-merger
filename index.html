      Microsoft 365 connection

      Set once per deployment — users never need to open this. To bake it in for everyone, put the same IDs in config.js instead; anything entered here overrides that, for this browser only.

      Your Microsoft 365 admin registers a single-page application in Azure AD and grants it the delegated Files.Read.All and Sites.Read.All permissions. Delegated means the app acts as each signed-in user and can never reach a file that user could not already open. See README.md for the exact request to send your admin.

      Leave as common unless your admin gives you a specific tenant ID.

      Must be added as a Single-page application platform, exactly as shown.

      Dropbox connection

      Only needed for the Link filler. Create a Dropbox app, tick all four of account_info.read, files.metadata.read, sharing.read and sharing.write on its Permissions tab, click Submit, then paste its App key. It is a public client using PKCE, so there is no app secret.

      Adding a permission does not upgrade an existing sign-in. If you connected before ticking them, disconnect and connect again or every call fails with missing_scope.
